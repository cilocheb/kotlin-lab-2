# Kotlin Tasks — решение задач по Kotlin

## Описание проекта

Проект содержит решения практических задач по языку Kotlin, охватывающих:
- Базовый синтаксис
- Null-безопасность
- Коллекции и функции высшего порядка
- Корутины

## Технологии
- **Язык:** Kotlin (JVM)
- **Сборка:** Gradle (Kotlin DSL)
- **Тестирование:** Встроенные тесты в `main()`

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_логин/kotlin-tasks.git
   ```
2. Откройте проект в IntelliJ IDEA.
3. Запустите файл `Main.kt` (Run).
4. Результаты тестов появятся в консоли.

## Структура проекта
- `src/main/kotlin/Main.kt` — точка входа и тестирование.
- `src/main/kotlin/tasks/` — решения задач (BasicSyntax, NullSafety, Collections, Coroutines, DataClasses).
