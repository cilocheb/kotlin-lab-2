## 4. Контрольные вопросы

### 1. В чём разница между val и var?

val — переменная, значение которой нельзя переназначить после инициализации. var — переменная, значение которой можно изменять. В Kotlin рекомендуется использовать val, если изменение значения не требуется.

### 2. Что такое null-безопасность и как она реализована в Kotlin?

Null-безопасность — механизм, позволяющий безопасно работать с отсутствующими значениями и предотвращать NullPointerException. Для nullable-переменных используется знак ?. Основные операторы: ?. — безопасный вызов, ?: — значение по умолчанию, !! — принудительное обращение к nullable-значению.

### 3. Что такое tailrec и когда его следует использовать?

tailrec — модификатор Kotlin, позволяющий оптимизировать хвостовую рекурсию. Он используется, когда рекурсивный вызов является последней операцией функции. Компилятор преобразует такую рекурсию в цикл, уменьшая риск переполнения стека.

### 4. Чем filter отличается от filterNotNull?

filter фильтрует элементы коллекции по заданному условию. filterNotNull удаляет все null-элементы из коллекции nullable-значений и возвращает список элементов без null.

### 5. Что такое функции высшего порядка? Приведите пример.

Функции высшего порядка принимают другие функции в качестве параметров или возвращают функции. Например, map принимает лямбда-функцию и преобразует каждый элемент коллекции.

Пример:
```kotlin
val numbers = listOf(1, 2, 3)
val doubled = numbers.map { it * 2 }
```

### 6. Что такое корутины и зачем они нужны?

Корутины — механизм Kotlin для асинхронного программирования. Они позволяют приостанавливать выполнение задач без блокировки потока. Используются для задержек, сетевых запросов и параллельной обработки.

### 7. В чём разница между launch и async?

launch запускает корутину и возвращает Job, не предоставляя результат вычисления. async запускает корутину и возвращает Deferred, из которого можно получить результат через await().

### 8. Что такое suspend-функция?

suspend-функция может приостанавливать выполнение корутины без блокировки потока. Она вызывается из другой suspend-функции или из coroutine builder, например runBlocking.

### 9. Как работает groupBy в Kotlin?

groupBy группирует элементы коллекции по заданному признаку. Возвращает Map, где ключ — признак группировки, а значение — список соответствующих элементов.

### 10. Что такое data class и зачем он нужен?

data class — специальный класс Kotlin для хранения данных. Компилятор автоматически генерирует equals(), hashCode(), toString(), copy() и componentN().
